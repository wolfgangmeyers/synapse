Do not trim into another identity, resolve display names, strip source prefixes, or accept `from`. Target can be any existing active identity on the same router, including a never-connected managed identity. This is single-user visual metadata, not a new role/target authorization system.

Reconcile current state and retry only with a fresh explicit call. No target mailbox message or runtime/goal change. Fresh repeated true/false is idempotent; different fresh writes serialize. Replaying an old invocation must not reapply it over a newer write. Preserve existing checked-invocation recovery behavior: an already checked/unknown invocation cannot obtain fresh execution authority; report replay/unknown honestly rather than silently execute it again. A new explicit call is the retry mechanism.

Expose to embedded root and worker roles through ordinary configured-tool/workflow restrictions, default enabled. Not a system escape. Do not automatically add to nested subagents.
