# Mailbox v1 contract manifest

This directory freezes the input to the Go router parity work. The current Node router remains the running implementation. These files describe the surface that later differential fixtures will fill with exact outcomes.

## Sources

- HTTP routing: `harness/router.js`
- Shared frame and envelope validation: `protocol/v1/schema.json`
- Persistence and migrations: `harness/db.js` and `harness/migrations/001_initial.sql` through `020_prompt_templates.sql`
- Launcher: `tools/run_router.mjs`

`manifest.json` is the machine-readable route and frame inventory. `http-outcomes.json` and `frame-cases.json` are fixture scaffolds. `generated-fields.json` is the only field-normalization allowlist.

The outcome fixtures will add, for every method/path, successful status, error status/code/message, response headers, and request-validation rules. Empty `route_outcomes` means that work has not been implemented in this scaffolding seam.

## WebSocket surface

The endpoint is `/v1/agents`. Client and server frame type inventories are in `manifest.json`; their field contracts are defined by `protocol/v1/schema.json`.

The frame fixtures reserve cases for required, omitted, and unknown fields; malformed JSON and UTF-8; unpaired surrogates; binary messages; and close codes `1009` (frame too large), `4003` (lease expired), `4001` (replacement), `4009` (duplicate identity), and `1011` (internal error).

## Generated values

Differential comparisons keep sender-supplied timestamps, sequence numbers, state transitions, and ordering byte-for-byte. Only the field names in `generated-fields.json` may be normalized. The Go test seam will inject one clock and one sequenced ID source and will report their call ledgers at fixture-step boundaries.

## CORS decision gate

The current Node source applies wildcard CORS to Origin-bearing API requests, including `/v1/agents`. An existing model-catalog test expects a `403` response. The source/test conflict is recorded in `manifest.json` and `http-outcomes.json` as `oracle_pending`.

This seam records the conflict only. It does not change CORS code, CORS tests, or any HTTP route outcome.

## Scope of this seam

This commit adds contract inventory files and the Go module test/build harness plus deterministic clock and ID utilities. The existing `router-proxy` remains unchanged and continues to build as its own proxy. No Go HTTP route, WebSocket handler, SQLite store, migration, scheduler, or launcher behavior is implemented here.
