# Mailbox v1 contract manifest

This directory defines the supported Go Mailbox router contract. These files describe the surface that later fixtures will fill with exact outcomes.

## Sources

- HTTP routing: `router-proxy/internal/transport/http.go`
- WebSocket routing: `router-proxy/internal/transport/websocket.go`
- Shared frame and envelope validation: `protocol/v1/schema.json`
- Persistence and migrations: `router-proxy/internal/store/` and `router-proxy/internal/store/migrations/`
- Supported launcher: `tools/run_router.sh`

`manifest.json` is the machine-readable route and frame inventory. `http-outcomes.json` and `frame-cases.json` are fixture scaffolds. `generated-fields.json` is the only field-normalization allowlist.

## Managed launch surface

Managed mode is disabled by default and never changes the legacy wildcard CORS or WebSocket contract. When enabled, `POST /v1/ui-session` accepts only `{}` and returns a one-time CSRF value with an `HttpOnly`, `SameSite=Strict`, `/v1` cookie named `mecha_ui_session`. Launches require that cookie, `X-Mecha-CSRF`, `Content-Type: application/json`, and a canonical UUID `X-Request-ID`. The closed launch body permits only `name`, `cwd`, `model`, and `initial_instruction`; the initial instruction is limited to 32 KiB.

Launch operations are durably idempotent by session identity, method, and request ID. Exact canonical path/body replays return the immutable original `202`; a changed path or body returns `409 IDEMPOTENCY_CONFLICT`. The managed child is a direct Pi RPC process and is not a `/v1/agents` WebSocket client or tmux window. The projection endpoint returns `{generated_at, projection_version, agent}` and exposes only safe managed identity/state fields. Ready managed agents are appended to authenticated `GET /v1/agents` responses with `source: "router-managed"`; unauthenticated legacy responses are unchanged.

Present valid managed Origins are reflected with credentials and `Vary: Origin`; malformed Origins return `422 VALIDATION_FAILED`; requests without Origin remain valid without CORS headers. Managed preflights return `204` only for valid or absent Origins.

## WebSocket surface

The endpoint is `/v1/agents`. Client and server frame type inventories are in `manifest.json`; their field contracts are defined by `protocol/v1/schema.json`.

The frame fixtures reserve cases for required, omitted, and unknown fields; malformed JSON and UTF-8; unpaired surrogates; binary messages; and close codes `1009` (frame too large), `4001` (lease expired or replacement), `4003` (lease_not_active), `4009` (duplicate identity), and `1011` (internal error).

## Generated values

Differential comparisons keep sender-supplied timestamps, sequence numbers, state transitions, and ordering byte-for-byte. `generated-fields.json` permits normalization only for an explicit path and context. Caller-owned and echoed `created_at`, `frame_id`, `request_id`, and `control_id` are protected contexts. The Go test seam will inject one clock and one sequenced ID source and will report their call ledgers at fixture-step boundaries.

## CORS behavior

The supported Go router applies wildcard CORS to every Origin-bearing API request, including `/v1/agents`. Origin-bearing `OPTIONS` requests return `204` with the wildcard CORS headers. `OPTIONS` without Origin returns the normal `404` JSON error. The former model-catalog `403` expectation is retired and covered by regression tests.

## Scope of the transport slice

The supported Go command opens an isolated persistent SQLite database and serves health, capabilities, agents, conversations, messages, reminders, prompt templates, attachments, and the `/v1/agents` WebSocket over the transport package, with CORS and correlation headers. It includes registration, delivery, receipts, activity, model and goal projections, arrival, and lifecycle wire handling. This contract does not claim browser proof.
