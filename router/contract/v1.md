# Mailbox v1 contract manifest

This directory freezes the input to the Go router parity work. The supported launcher runs the Go router; the Node router remains available as an explicit rollback path. These files describe the surface that later differential fixtures will fill with exact outcomes.

## Sources

- HTTP routing: `harness/router.js`
- Shared frame and envelope validation: `protocol/v1/schema.json`
- Persistence and migrations: `harness/db.js` and `harness/migrations/001_initial.sql` through `020_prompt_templates.sql`
- Supported launcher: `tools/run_router.sh`
- Node rollback implementation: `tools/run_router.mjs`

`manifest.json` is the machine-readable route and frame inventory. `http-outcomes.json` and `frame-cases.json` are fixture scaffolds. `generated-fields.json` is the only field-normalization allowlist.

The outcome fixtures will add, for every method/path, successful status, error status/code/message, response headers, and request-validation rules. Empty `route_outcomes` means that work has not been implemented in this scaffolding seam.

## WebSocket surface

The endpoint is `/v1/agents`. Client and server frame type inventories are in `manifest.json`; their field contracts are defined by `protocol/v1/schema.json`.

The frame fixtures reserve cases for required, omitted, and unknown fields; malformed JSON and UTF-8; unpaired surrogates; binary messages; and close codes `1009` (frame too large), `4001` (lease expired or replacement), `4003` (lease_not_active), `4009` (duplicate identity), and `1011` (internal error).

## Generated values

Differential comparisons keep sender-supplied timestamps, sequence numbers, state transitions, and ordering byte-for-byte. `generated-fields.json` permits normalization only for an explicit path and context. Caller-owned and echoed `created_at`, `frame_id`, `request_id`, and `control_id` are protected contexts. The Go test seam will inject one clock and one sequenced ID source and will report their call ledgers at fixture-step boundaries.

## CORS behavior

The current Node source applies wildcard CORS to every Origin-bearing API request, including `/v1/agents`. Origin-bearing `OPTIONS` requests return `204` with the wildcard CORS headers. `OPTIONS` without Origin returns the normal `404` JSON error. The former model-catalog `403` expectation is retired and covered by regression tests.

## Scope of the transport slice

The Go command now opens an isolated persistent SQLite database, serves health, capabilities, agents, conversations, messages, reminders, prompt templates, attachments, and the `/v1/agents` WebSocket over the transport package, with CORS and correlation headers. The slice includes registration, delivery, receipts, activity, model and goal projections, arrival, and lifecycle wire handling. Remaining Node parity work is tracked separately; this slice does not claim browser proof.
