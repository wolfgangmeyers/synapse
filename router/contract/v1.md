# Mailbox v1 contract manifest

This directory defines the supported Go Mailbox router contract. The preferred launcher is `tools/run_router.sh`; the Node router remains available only as an explicit rollback and differential-test reference. These files describe the surface that later differential fixtures will fill with exact outcomes.

## Sources

- HTTP routing: `router-proxy/internal/transport/http.go`
- WebSocket routing: `router-proxy/internal/transport/websocket.go`
- Shared frame and envelope validation: `protocol/v1/schema.json`
- Persistence and migrations: `router-proxy/internal/store/` and `router-proxy/internal/store/migrations/`
- Supported launcher: `tools/run_router.sh`
- Legacy Node rollback sources: `harness/router.js`, `harness/db.js`, and `harness/migrations/`

`manifest.json` is the machine-readable route and frame inventory. `http-outcomes.json` and `frame-cases.json` are fixture scaffolds. `generated-fields.json` is the only field-normalization allowlist.

The outcome fixtures will add, for every method/path, successful status, error status/code/message, response headers, and request-validation rules. Empty `route_outcomes` means that work has not been implemented in this scaffolding seam.

## WebSocket surface

The endpoint is `/v1/agents`. Client and server frame type inventories are in `manifest.json`; their field contracts are defined by `protocol/v1/schema.json`.

The frame fixtures reserve cases for required, omitted, and unknown fields; malformed JSON and UTF-8; unpaired surrogates; binary messages; and close codes `1009` (frame too large), `4001` (lease expired or replacement), `4003` (lease_not_active), `4009` (duplicate identity), and `1011` (internal error).

## Generated values

Differential comparisons keep sender-supplied timestamps, sequence numbers, state transitions, and ordering byte-for-byte. `generated-fields.json` permits normalization only for an explicit path and context. Caller-owned and echoed `created_at`, `frame_id`, `request_id`, and `control_id` are protected contexts. The Go test seam will inject one clock and one sequenced ID source and will report their call ledgers at fixture-step boundaries.

## CORS behavior

The supported Go router applies wildcard CORS to every Origin-bearing API request, including `/v1/agents`. Origin-bearing `OPTIONS` requests return `204` with the wildcard CORS headers. `OPTIONS` without Origin returns the normal `404` JSON error. The former model-catalog `403` expectation is retired and covered by regression tests. The legacy Node router has the same behavior for explicit rollback and differential testing.

## Scope of the transport slice

The supported Go command opens an isolated persistent SQLite database and serves health, capabilities, agents, conversations, messages, reminders, prompt templates, attachments, and the `/v1/agents` WebSocket over the transport package, with CORS and correlation headers. It includes registration, delivery, receipts, activity, model and goal projections, arrival, and lifecycle wire handling. The legacy Node implementation remains available for explicit rollback and differential tests. This contract does not claim browser proof.
